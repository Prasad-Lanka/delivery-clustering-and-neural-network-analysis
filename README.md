# Delivery Clustering and Neural Network Analysis

This is a beginner-level machine learning project focused on analyzing food delivery data using clustering techniques and a neural network model. The project applies K-Means Clustering, Hierarchical Clustering, and Neural Network classification to understand delivery patterns and model performance.

## Project Overview

The main objective of this project is to analyze food delivery records and identify useful patterns related to delivery performance. Clustering models are used to group similar delivery records, while a neural network model is used for prediction/classification.

This project was completed as part of my machine learning assignment work.

## Dataset

The dataset used in this project is:

`Food_Delivery_Time_Prediction.csv`

The dataset contains food delivery-related features such as:

- Delivery time
- Delivery distance
- Delivery person experience
- Restaurant rating
- Customer rating
- Order cost
- Tip amount
- Other delivery-related details

## Models and Techniques Used

The following machine learning techniques were used:

1. K-Means Clustering
2. Hierarchical Clustering
3. Neural Network Model

## Workflow

The project follows these steps:

1. Importing required libraries
2. Loading the dataset
3. Data preprocessing
4. Feature selection
5. Feature scaling
6. Applying K-Means Clustering
7. Applying Hierarchical Clustering
8. Training a Neural Network model
9. Evaluating model performance
10. Comparing results
11. Preparing final reports and insights

## Model Evaluation

The models were evaluated using suitable metrics and visualizations.

For clustering models, the analysis includes:

- Cluster formation
- Cluster visualization
- Comparison of delivery patterns across clusters

For the neural network model, the evaluation includes:

- Accuracy
- Loss
- Model performance comparison
- Interpretation of results

## Key Insights

- Clustering helps identify groups of similar delivery records.
- K-Means and Hierarchical Clustering are useful for understanding delivery patterns.
- Neural networks can be applied for prediction tasks after preprocessing and feature scaling.
- Delivery-related factors such as distance, ratings, experience, and cost may influence delivery performance.

## Important Note

This is a beginner-level machine learning assignment created for learning purposes. Some features may be closely related to the target variable, so the results should be understood mainly as practice in preprocessing, clustering, neural network modeling, and evaluation rather than a fully independent real-world prediction system.
